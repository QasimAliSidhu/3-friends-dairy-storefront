# 3 Friends Dairy Storefront — public demo

Try it locally: choose a 500 g jar, change the quantity, and copy the enquiry message. Small businesses can study the browsing-to-enquiry pattern before adding payment or checkout.

## Try it

```console
python preview.py
```

[3 Friends Dairy Storefront quick-start guide](https://github.com/QasimAliSidhu/3-friends-dairy-storefront/blob/main/docs/QUICKSTART.md)

## Exercise

Select 500 g desi ghee, add it to the enquiry list, change the quantity, and prepare a fictional enquiry. Confirm that nothing is submitted automatically.
