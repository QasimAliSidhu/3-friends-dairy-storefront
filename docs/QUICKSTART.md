# Try 3 Friends Dairy Storefront

## Start here

Clone this repository and open a terminal in its root. All examples below use fictional inputs.

The preview uses the Python standard library. Open the local URL printed by the command. Contact addresses are placeholders.

```console
python preview.py
```

## A useful exercise

Select 500 g desi ghee, add it to the enquiry list, change the quantity, and prepare a fictional enquiry. Confirm that nothing is submitted automatically.
